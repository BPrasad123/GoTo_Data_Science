Algos
=======================
Linear Regression
-------------------
Assumptions:
	Linear relationship between input and output
	No multi correlation
	No outliers
	No auto correlation
	Residuals follow normal distribution
	Homoscedaticity of residuals

Solver:
	OLS
	Maximum Likelihood Estimation
	SGD

Implementations:
	sklearn.linear_model.LinearRegression: OLS
	Other linear models:
		sklearn.linear_model.Ridge: ‘auto’, ‘svd’, ‘cholesky’, ‘lsqr’, ‘sparse_cg’, ‘sag’, ‘saga’, ‘lbfgs’
		sklearn.linear_model.SGDRegressor: Can choose l1, l2 and elasticnet
		sklearn.linear_model.ElasticNet: Helps in feature selection
		sklearn.linear_model.Lasso: Helps in feature selection
		sklearn.linear_model.HuberRegressor: Robust to outliers

Evalaution:
	Coefficient of determination (R square)

SVM
-------------
Usage: 
	Classification - sklearn.svm.SVC
	Regression - sklearn.svm.SVR

Mechanism:
Hyperplanes separating input space into different classes. Distance from hyperplane to closest data point is called as margin. Hyperplanes can be linear or non-linear governed by kernel.
kernels -
	linear - regularization with C (how tolerant to misclassification) value
	rbf (radial basis function) - gamma (how correctly classification is done)
	poly - degree
optimization - non-convex function and uses geometric obtimization 

Techniques:
	Scaling help improve the performance
	
Assumptions:
	None

Pros and Cons:
	Pros -
		When data is clearly separable
		When number of features is higher than number of observations
		Effective for high dimension space
		Less memory footprint
	Cons -
		Not good for high volume of data
		Not good for noisy data

http://www.csie.ntu.edu.tw/~cjlin/papers/guide/guide.pdf


Hyperparameters to tune:
	kernels in [‘linear’, ‘poly’, ‘rbf’, ‘sigmoid’]
	C (penalty) in [100, 10, 1.0, 0.1, 0.001]

KNN
---------------
Steps:

Decision Trees
--------------
Types:
	CHID - Oldest not in use any more
	ID3 - uses Information Gain (in terms of entropy). Information Gain is the decrease or increase in Entropy value when the node is split. Only Classification.
	C4.5 - Improved version of ID3. It uses Gain Ratio that is normalization of Information Gain to handle bias.
	CART - Uses Gini Index and Gini gain. Gini Index: The probability of assigning a wrong label to a sample by picking the label randomly. Gini Gain = Gini (parent node) - Gini(child node). CART can also handle regression problem using a different splitting criterion: Mean Squared Error (MSE) to determine the splitting points. Supports both Classification and Regression.

Usage:
	Sklearn comes with CART only.
	Classification - DecisionTreeClassifier (criterion{“gini”, “entropy”, “log_loss”}, default=”gini”)
	Regression - DecisionTreeRegressor (criterion{“squared_error”, “friedman_mse”, “absolute_error”, “poisson”}, default=”squared_error”) 

Mechanism:
	 - No matter which decision tree algorithm you are running: ID3, C4.5, CART, CHAID or Regression Trees. They all look for the feature offering the highest information gain. Then, 			they 	add a decision rule for the found feature and build an another decision tree for the sub data set recursively until they reached a decision.

Hyperparameters to tune:
	max_max_features [1 to 20, ‘sqrt’, ‘log2’]
	min_samples_split
	min_samples_leaf
	max_features
	min_impurity_decrease

https://www.vebuso.com/2020/01/decision-tree-intuition-from-concept-to-application/
https://sefiks.com/2018/08/27/a-step-by-step-cart-decision-tree-example/


Random Forest
--------------
Usage:
	RandomForestRegressor (criterion{“squared_error”, “absolute_error”, “friedman_mse”, “poisson”}, default=”squared_error”)
	RandomForestClassifier (criterion{“gini”, “entropy”, “log_loss”}, default=”gini”)

Mechanism:
	Uses a collection of trees
	Random sample of observations for each individual tree
	For each node in the individual tree random features are selected to make the trees uncorrelated
	Bootstrapping the data and then using an aggregate to make a prediction is called Bagging
	Maximum voting or taking the averages of predictions for final prediction
	

Optimization:
	If overfit, then increase n_estimators and decrease max depth.

Hyperparameters:
	max_depth
	min_samples_leaf
	min_samples_split
	max_features [1 to 20, ‘sqrt’, ‘log2’, p/3]
	max_leaf_nodes
	n_n_estimators in [10, 100, 1000]

Note: Bootstrapping is sampling with replacements.

Difference:
	XGBoost applies level-wise (horizontal) tree growth whereas LightGBM applies leaf-wise tree growth (vertically) and this makes LightGBM faster. The leaf-wise algorithm chooses the leaf with maximum reduction in the loss function. This function was later added to XGBoost as well.

LightGBM
---------------------
Boosting techniques:
	GBDT - Traditional one. Stable, slow but efficient.
	DART - Uses dropout on trees. More accurate but too many settings.
	GOSS (Gradient-based one side sampling) - Difficult data points have larger gradient, hence model samples from data with larger gradients. Fast and converges faster.
	RF - Behaves like Random Forest

Uses leaf-wise growth technique, hence prone to overfitting.

Use to handle overfitting:
	Small max_bin
	small num_leaves
	min_data_in_leaf
	bagging_fraction
	feature_fraction
	bigger training data
	max_depth
	lamda_l1, lambda_l2
	min_gain_to_split

Recommendations:
	use smaller learning_rate with larger num_iterations
	early_stopping_rounds
	set categorical feature manually
	is_unbalance vs scale_pos_weight


Missing values:
	default NAN. 
	During training: For numeric, assign to side resulting in more loss in error. For categorical assign to right
	During prediction: For numeric, assign to zero. For categorical, if seen already then left of split else right

Categorical encoding:
	Integer encoding and fisher technique used to find optimal split

PCA
-----
If there is linear relationship among the vectors, those are projected into smalled dimensions with eigen values and eigen vectors using covariance matrix.



So many disadvantages:
	assumes linearity among features
	cannot handle missing values
	sensitive to outliers
	need to rescale features
	suitable for continuous data only
	not interpretability

Steps:
1. Standardize the datapoints
2. Find the covariance matrix from the given datapoints
3. Carry out eigen-value decomposition of the covariance matrix
4. Sort the eigenvalues and eigenvectors

N-gram, Skip Gram and CBOW, Word2vec
------------------------------------

Isolation Forest
-----------------
Data partitioning is done using a set of trees. Isolation Forest provides an anomaly score looking at how isolated the point is in the structure. The anomaly score is then used to identify outliers from normal observations

Unsupervised algo and individual trees are binary trees. All the data points making it the depth of the RF tree are normal and the ones ending up with leaf nodes eary are treated as anomaly. 

-1 assigned to anomaly. +1 type assigned to normal data points. Different contamination parameter to be tried and data needs to be visualized and can be decided based on business context.

Affinity Propagation
--------------------

The key idea behind Affinity Propagation is that each data point can both act as an exemplar (representative) of its own cluster, and can also have a preference for being the exemplar of other data points. The algorithm seeks to find the exemplars that result in the highest total preference among all data points.

Algorithm by passing messages between data points.

Damping: Extennt to which current value is maintained with addition of new values.


Agglomorative Hierarchical Clustering

Starts with singletone clusters, merges pairs of closest clusters of until one big cluster is created.

AgglomerativeClustering(n_clusters = 5, affinity = 'euclidean', linkage ='ward')

Use dendograms, find the longest vertical line without crossing horizental lines.

K-MEANS
----------------

Steps:
	Randomly assign predefined number of clusters.
	Data points assigned to their nearest cluster centroids.
	Recalculate the cetroids and repeat the steps until the centroids are not moving.

Optimize
	n_init: 10 for initial
	tol: keep it low
	max_iter: There are n_init runs in general and each run iterates max_iter times
Initialization:
	Kmeans++

Elbow method to choose the number of clusters.

Evaluation:
	Dunn index. Ratio of minimum inter cluster distance to maximum of intra cluster distance. Higher the better.

Isolation Forest
------------------
In an Isolation Forest, randomly sub-sampled data is processed in a tree structure based on randomly selected features. The samples that travel deeper into the tree are less likely to be anomalies as they required more cuts to isolate them. Similarly, the samples which end up in shorter branches indicate anomalies as it was easier for the tree to separate them from other observations.

algorithm step by step:
When given a dataset, a random sub-sample of the data is selected and assigned to a binary tree.
Branching of the tree starts by selecting a random feature (from the set of all N features) first. And then branching is done on a random threshold ( any value in the range of minimum and maximum values of the selected feature).
If the value of a data point is less than the selected threshold, it goes to the left branch else to the right. And thus a node is split into left and right branches.
This process from step 2 is continued recursively till each data point is completely isolated or till max depth(if defined) is reached.
The above steps are repeated to construct random binary trees.

-1 is assigned to anomalies
